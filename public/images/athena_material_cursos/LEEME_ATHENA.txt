MATERIAL DEMO PARA CARGAR EN ATHENA
====================================

Este paquete contiene imágenes y datos de ejemplo para que tu catálogo de cursos se vea parecido al diseño moderno de referencia.

Contenido del ZIP:
- imagenes_cursos/hero-python-datos.png

- athena_cursos_demo.json
- athena_cursos_demo.csv

Cómo usarlo:
1. Entra como administrador a tu plataforma ATHENA.
2. Crea o edita cursos desde el módulo de cursos.
3. Para cada curso, copia el nombre, descripción, precio, descuento, nivel y duración desde el archivo JSON o CSV.
4. Sube la imagen correspondiente desde la carpeta imagenes_cursos.
5. Activa estas opciones para que salgan en el catálogo público:
   - is_published: true
   - open_enrollment: true
6. Para que se vea la etiqueta de oferta, coloca un discount_price menor que price.
7. Para que se vea la duración, coloca duration_hours mayor que 0.
